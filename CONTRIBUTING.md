# Contributing Guidelines
1. **Branch Naming:** Always use `feature/`, `bugfix/`, or `chore/` prefixes.
2. **PR Required:** Direct commits to main are blocked; all changes must be submitted via Pull Request.
3. **Review Required:** At least one approved code review is required before merging.
4. **Conventional Commits:** Write clear, structured commit messages (e.g., `feat: add database schema`).
